# AI Architecture Portfolio

A working portfolio for documenting an AI system architecture, the assumptions
behind it, and the decisions made along the way.

## Repository Layout

- `docs/`: numbered notes for each design session
- `diagrams/`: editable diagram sources and their exported PNG or SVG files
- `adr/`: architecture decision records, numbered in decision order
- `capstone/`: final architecture PDF and presentation slides

## How to Use

Begin with the framing notes in `docs/`, then follow the numbered sessions as
the architecture takes shape. Record significant choices in `adr/`, including
their context, alternatives, and consequences. Keep diagram sources alongside
their exports. Put completed presentation materials in `capstone/`.

Document scenario details, assumptions, constraints, and unresolved questions
in the session notes. Avoid treating unvalidated assumptions as production
requirements.
